## Адаптивные решения

- добавлен файл `css/responsive.css`;
- применён подход Mobile First;
- добавлены медиазапросы;
- адаптирована навигация;
- карточки на главной перестраиваются в 1, 2 и 3 колонки; в каталоге — в 1 и 2 колонки;
- с ширины 1024px фильтры каталога располагаются сбоку от карточек;
- для пластинки добавлены изображения 320 и 480px с `srcset` и `sizes`; остальные медиа ограничены шириной контейнера;
- адаптирована форма заявки;
- адаптирована таблица характеристик.

## Доступность
